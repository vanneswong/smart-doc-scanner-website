部署指南

一行命令，即刻运行。使用预构建镜像，或本地 Docker Compose 构建。

已在线部署 无需自建即可直接体验 scanner.zynotes.cn
使用腾讯云 TCR 镜像 · mikewong/scanner
docker pull ccr.ccs.tencentyun.com/mikewong/scanner:v0.4.2

docker run -d \
  --name smart-doc-scanner \
  --restart unless-stopped \
  -p 10030:8000 \
  -v scanner-data:/data \
  ccr.ccs.tencentyun.com/mikewong/scanner:v0.4.2
Docker Compose 本地构建
cd smart-doc-scanner
docker compose up -d --build
# 打开 http://localhost:8080

# 修改宿主机端口
SCANNER_PORT=9000 docker compose up -d

关键环境变量

DATA_DIR临时文件目录
MAX_UPLOAD_MB单张上传上限（默认 30）
MAX_PIXELS_MP解码像素上限（默认 48）
FILE_TTL_HOURS文件保留时间（默认 6 小时）
PROCESS_CONCURRENCY全分辨率处理并发数
SCANNER_PORTCompose 宿主机端口
