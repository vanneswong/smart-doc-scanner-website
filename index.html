核心能力

从「随手拍」到「正式扫描件」

一条完整的图像处理管线，把手机镜头下的褶皱、阴影、偏色与笔迹，转化为干净、标准的文档页面。

自动找边

Canny 多阈值 + 形态学梯度 + 亮纸掩膜。整张照片几乎都是纸面时自动回退整图，避免把表格或文字块误裁成纸张。

手动校正

识别不准时，在网页上直接拖动四个角点，贴合纸张边缘，实时重新预览最终效果。

透视校正

cv2.getPerspectiveTransform + 三次插值，把梯形、倾斜纸张摊平成标准矩形，同时完成去歪斜。

方向与旋转

按纸张比例自动判断横 / 纵向，并支持输出旋转 0° / 90° / 180° / 270° 校正文字方向。

去阴影

局部闭运算估计纸面亮度 + 20×20 网格逐通道白平衡，压制手影、弯曲纸张、渐变阴影与彩色灯光。

去彩色手写

局部色度 top-hat 检测红 / 蓝笔迹，按亮度阈值擦除笔迹，同时尽量保留被覆盖的印刷文字；印章、彩色 logo 等紧凑色块自动保留。

白平衡

以纸面高光为白点做白平衡，校正室内灯光与色温造成的整体偏色。

CLAHE 对比度增强

在 LAB-L 通道做限制对比度自适应直方图均衡，找回浅色文字与褪色笔画。

背景纯白

每个局部区域独立把纸面拉到纯白，同时保留文字、铅笔和印章颜色，接近扫描仪的纸白效果。

去噪

双边滤波三档强度；黑白模式额外做强边缘保护降噪，避免纸纹与 JPEG 噪点变成黑点。

锐化

反锐化掩模，强度 0–100 可调，让文字边缘清晰锐利而不显生硬。

色彩模式

彩色 / 灰度 / 黑白三种输出。黑白模式使用强双边滤波 + 自适应阈值 + 中值滤波 + 连通域小噪点清理。

纸张尺寸

A4 默认 300 DPI（2480 × 3508）、A5、A3、Letter、Legal、自动尺寸与自定义毫米尺寸（20–2000 mm）。

多页 PDF 导出

页面按纸张尺寸排版，自动处理横 / 纵向；彩色 / 灰度用 JPEG 直嵌，黑白用 1-bit Flate 压缩。

图片导出

单页直接下载 JPEG（彩色 / 灰度）或 PNG（黑白）；多页一键打包为 ZIP，按页顺序命名。

处理管线

一条管线，端到端增强

从上传到成品，每一步都经过精心调校，核心是「两层估计」的去阴影策略。

01

输入修正

EXIF 方向修正 · 限制长边 · JPEG 解码，统一进入处理流程。

02

自动找边

在 1100px 缩略图上多策略检测四边形：多阈值 Canny、形态学梯度、亮纸掩膜，按面积 × 直角评分选最优。

03

透视变换

透视变换到目标纸张像素（A4@300dpi = 2480×3508），三次插值摊平。

04

增强链路

去噪 → 白平衡 → 去阴影（闭运算 + 网格白平衡）→ 去彩色手写 → CLAHE → 背景纯白 → 锐化。

05

模式输出

彩色 / 灰度 / 黑白自适应阈值，输出 JPEG 或 PNG，并支持多页 PDF / ZIP。

去阴影的关键：两层估计

闭运算

用约短边 3.5% 的核对纸面做形态学闭运算，填掉文字笔画与窄折痕，得到平滑的纸面亮度图。核太小填不掉折痕，太大会把渐变阴影一起抬高。

网格白平衡

在 20×20 个局部块上分别取 85 分位纸面颜色，逐通道除以该颜色并把目标设为纯白，消除渐变、弯曲纸张明暗与蓝 / 黄灯光偏色。

技术栈

轻量、自托管、隐私优先

没有账号系统，没有云端上传，所有图片只在本机临时目录处理。

Python 3.12 + FastAPI + OpenCV

高性能图像处理后端，原生 OpenCV 算法，支持交互式 API 文档。

原生 HTML / CSS / JavaScript

前端无 Node 构建步骤，打开即用，拖放 / 粘贴 / 手机拍照多种上传方式。

单容器 Docker 部署

非 root 运行，约 120 MB 镜像；Docker Compose 一键启动，环境变量灵活配置。

隐私与自动清理

原图与结果只保存在本机临时目录，默认 6 小时后自动清理，最多 800 个文件 / 目录。

快速开始

一行命令，即刻运行

使用预构建镜像，或本地 Docker Compose 构建。

使用腾讯云 TCR 镜像
docker pull ccr.ccs.tencentyun.com/mikewong/canner:v0.3.0

docker run -d \
  --name smart-doc-scanner \
  --restart unless-stopped \
  -p 10030:8000 \
  -v scanner-data:/data \
  ccr.ccs.tencentyun.com/mikewong/canner:v0.3.0
Docker Compose 本地构建
cd smart-doc-scanner
docker compose up -d --build
# 打开 http://localhost:8080

# 修改宿主机端口
SCANNER_PORT=9000 docker compose up -d

关键环境变量

DATA_DIR临时文件目录
MAX_UPLOAD_MB单张上传上限（默认 30）
MAX_PIXELS_MP解码像素上限（默认 48）
FILE_TTL_HOURS文件保留时间（默认 6 小时）
PROCESS_CONCURRENCY全分辨率处理并发数

HTTP API

完整、可编程的接口

启动后可在 /docs 查看交互式 OpenAPI 文档。

POST

/api/detect

上传图片，返回任务 ID 与自动检测到的纸张四角坐标。

POST

/api/redetect

对同一张原图重新运行边缘检测。

POST

/api/process

按四角、纸张、DPI、色彩模式与增强参数生成扫描件，支持快速预览。

POST

/api/pdf

将多个结果按纸张尺寸排版合并为多页 PDF。

POST

/api/zip

多页结果一键打包 ZIP，彩色 / 灰度为 JPG、黑白为 PNG。

GET

/healthz

健康检查，配合 Docker / 反向代理探活。

说明与限制

坦率地说明边界

了解适用场景，才能用得更好。

本应用没有登录鉴权，适合局域网 / 内网使用；暴露公网时请放在带认证的反向代理后面。
支持 JPG / PNG / WebP；iPhone HEIC 通常由浏览器转成 JPEG，服务器直接收到 HEIC 会返回「无法识别该图片格式」。
「自动尺寸」按检测到的四边形比例输出，不代表真实物理尺寸；需要标准纸张请选 A4 / A5 等预设。
页面列表仅保存在浏览器内存中，刷新页面后需重新生成；结果文件默认 6 小时后清理。
「去彩色手写」仅针对红 / 蓝等有颜色笔迹；黑色签字笔、铅笔与印刷文字难以可靠区分，不在功能范围内。
去阴影默认强度 100；如需保留纸张纹理 / 浅灰底纹，可在界面下调。
