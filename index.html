核心能力

从「随手拍」到「正式扫描件」

一条完整的图像处理管线，把手机镜头下的褶皱、阴影、偏色与笔迹，转化为干净、标准的文档页面。

自动找边

Canny 多阈值 + 形态学梯度 + 亮纸掩膜，整张照片几乎都是纸面时自动回退整图，避免误裁。

透视校正

透视变换 + 三次插值，把梯形、倾斜纸张摊平成标准矩形，同时完成去歪斜。

去阴影

局部闭运算估计纸面亮度 + 20×20 网格逐通道白平衡，压制手影、弯曲纸张与彩色灯光。

去彩色手写

局部色度 top-hat 检测红 / 蓝笔迹，擦除笔迹但保留被覆盖的印刷文字，印章与彩色 logo 自动保留。

多页 PDF 导出

页面按纸张尺寸排版，自动处理横 / 纵向；彩色 / 灰度用 JPEG 直嵌，黑白用 1-bit Flate 压缩。

图片导出

单页直接下载 JPEG（彩色 / 灰度）或 PNG（黑白）；多页一键打包为 ZIP，按页顺序命名。

页面拖动排序

扫描件卡片支持拖动排序，松开后自动重排编号，PDF 与 ZIP 按新顺序导出。
