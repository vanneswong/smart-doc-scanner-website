首页/HTTP API

HTTP API

完整、可编程的接口。启动后可在 /docs 查看交互式 OpenAPI 文档。

POST

/api/detect

上传图片，返回任务 ID 与自动检测到的纸张四角坐标。

POST

/api/redetect

对同一张原图重新运行边缘检测。

POST

/api/process

按四角、纸张、DPI、色彩模式与增强参数生成扫描件，支持快速预览。

POST

/api/pdf

将多个结果按纸张尺寸排版合并为多页 PDF。

POST

/api/zip

多页结果一键打包 ZIP，彩色 / 灰度为 JPG、黑白为 PNG。

GET

/healthz

健康检查，配合 Docker / 反向代理探活。

GET

/files/{id}

读取临时原图与结果文件。

GET

/docs

OpenAPI 交互式文档，可在线调试所有接口。
